Max-- Compiler

C, C++
GitHub

A compiler for my own language I invented, called max--. It is written end to end, including a lexer, parser, IR generator, register allocator, and code generator.

It supports basic arithmetic, variables, functions, and control flow. The frontend is written in C, and the backend is written in C++.

// Example max-- code
fn add(int x, int y): int {
    return x + y;
}

fn main(): int {
    int x = 1;
    int y = 2;
    int i = 0;
    while (i < 5) {
        if (i - x == 0 or i - y == 0) {
            print(add(x, y)); // 3
        }
        else {
            print(2 * (add(x, y))); // 6
        }
        i = i + 1;
    }

    return 0;
} // Prints: 6 3 3 6 6
